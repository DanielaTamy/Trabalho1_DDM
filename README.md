# Aplicativo 01

Aplicativo desenvolvido para a disciplina Desenvolvimento de Dispositivos Móveis.

O FlagQuiz apresenta cinco bandeiras sorteadas e desafia o jogador a identificar os países. Cada resposta correta vale 20 pontos.
